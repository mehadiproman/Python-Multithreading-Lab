# Python Multithreading Lab

An experiment-driven exploration of Python multithreading,
concurrency, synchronization, thread safety, and worker patterns.

## Why This Repository Exists

The goal of this repository is not simply to learn Python's
threading syntax.

The goal is to understand:

- Why threads exist
- How threads execute
- How threads communicate
- What can go wrong with shared state
- How synchronization solves concurrency problems
- How threading patterns appear in real backend systems

## Learning Method

Each concept follows:

Problem
→ Prediction
→ Experiment
→ Observation
→ Explanation
→ Solution
→ Real-world application
